# Parla Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Una app de macOS que escucha español por el micrófono y muestra en una ventana flotante cómo se dice en inglés y por qué.

**Architecture:** Dos módulos. `Core` es un paquete SPM sin UI ni frameworks de Apple más allá de Foundation: contiene el segmentador de frases, el cliente de la API de Claude y el parser SSE, y se prueba con `swift test` sin Xcode. `App` es el target de Xcode: captura de audio, transcripción con `SpeechAnalyzer`, panel flotante, persistencia con SwiftData y barra de menú. La frontera entre ambos es el protocolo `Explainer` y el tipo `Card`.

**Tech Stack:** Swift 6.3, swift-testing, SPM + XcodeGen, Speech.framework (macOS 26), SwiftData, AppKit/SwiftUI, KeyboardShortcuts 3.0.1, API de Anthropic vía URLSession.

**Spec:** `docs/superpowers/specs/2026-08-24-voz-a-ingles-design.md`

## Global Constraints

- Deployment target **macOS 26.0**. `Package.swift` debe declarar `// swift-tools-version:6.2` — `.macOS(.v26)` no existe en 6.1.
- **Una sola dependencia externa:** `sindresorhus/KeyboardShortcuts` desde `3.0.1`. No añadir ninguna otra sin aprobación explícita.
- **`Core` no puede importar SwiftData, AppKit, SwiftUI ni Speech.** El plugin de macros de SwiftData no existe en Command Line Tools; cualquier `@Model` en `Core` rompe `make test` hasta que Xcode esté instalado. La persistencia vive solo en `App`.
- **La API key solo en Keychain.** Nunca en `UserDefaults`, nunca en un archivo del repositorio, nunca en un test.
- Modelo: `claude-opus-5`. Cabecera `anthropic-version: 2023-06-01`. Cabecera beta `server-side-fallback-2026-07-01`.
- Textos de la interfaz y de las explicaciones **en español**. Las traducciones, en inglés.
- Tareas 1-7 no requieren Xcode. Tareas 8-14 sí.

`Core/Sources/ParlaCore/UtteranceSegmenter.swift`:

```swift
import Foundation

/// Decide dónde termina una frase.
///
/// Máquina de estados pura: no tiene reloj propio ni duerme. Quien la usa le
/// entrega los eventos y la hora, y llama a `tick` periódicamente.
public struct UtteranceSegmenter: Sendable {

    public struct Config: Sendable {
        /// Silencio que cierra una frase.
        public var silenceGap: TimeInterval
        /// Por encima de esto se corta sin esperar al silencio, para no dejar
        /// al usuario mirando un esqueleto durante medio minuto.
        public var maxCharacters: Int
        /// Por debajo de esto se descarta sin gastar una llamada a la API.
        public var minCharacters: Int

        public init(silenceGap: TimeInterval = 0.9,
                    maxCharacters: Int = 240,
                    minCharacters: Int = 3) {
            self.silenceGap = silenceGap
            self.maxCharacters = maxCharacters
            self.minCharacters = minCharacters
        }
    }

    private let config: Config
    private var pieces: [String] = []
    private var startedAt: Date?
    private var lastActivityAt: Date?

    public init(config: Config = Config()) {
        self.config = config
    }

    /// Entrega un evento de transcripción. Devuelve una frase si este evento la cierra.
    public mutating func ingest(_ event: TranscriptEvent, at time: Date) -> Utterance? {
        if startedAt == nil { startedAt = time }
        lastActivityAt = time

        guard case .final(let text) = event else {
            return nil   // los parciales solo mantienen viva la frase
        }

        let trimmed = text.trimmingCharacters(in: .whitespacesAndNewlines)
        guard !trimmed.isEmpty else { return nil }
        pieces.append(trimmed)

        return currentText.count >= config.maxCharacters ? flush() : nil
    }

    /// Llamar periódicamente. Devuelve una frase si el silencio ya la cerró.
    public mutating func tick(at time: Date) -> Utterance? {
        guard !pieces.isEmpty, let last = lastActivityAt else { return nil }
        guard time.timeIntervalSince(last) >= config.silenceGap else { return nil }
        return flush()
    }

    private var currentText: String {
        pieces.joined(separator: " ")
    }

    private mutating func flush() -> Utterance? {
        let text = currentText
        let began = startedAt
        pieces.removeAll()
        startedAt = nil
        lastActivityAt = nil

        guard text.count >= config.minCharacters, let began else { return nil }
        return Utterance(text: text, startedAt: began)
    }
}
```

`Core/Sources/ParlaCore/SSEParser.swift`:

```swift
import Foundation

public enum SSEEvent: Sendable, Equatable {
    case textDelta(String)
    case messageDelta(stopReason: String?)
    case done
}

/// Traduce el stream SSE de la API de Messages a eventos útiles.
///
/// Lleva la cuenta de qué índices de bloque son de tipo `text`, para descartar
/// los deltas de los bloques `thinking`, que en Opus 5 llegan antes.
public struct SSEParser: Sendable {

    private var textBlockIndices: Set<Int> = []

    public init() {}

    public mutating func consume(line: String) -> [SSEEvent] {
        guard line.hasPrefix("data:") else { return [] }
        let payload = line.dropFirst("data:".count).trimmingCharacters(in: .whitespaces)
        guard let data = payload.data(using: .utf8),
              let root = try? JSONSerialization.jsonObject(with: data) as? [String: Any],
              let type = root["type"] as? String
        else { return [] }

        switch type {
        case "content_block_start":
            if let index = root["index"] as? Int,
               let block = root["content_block"] as? [String: Any],
               block["type"] as? String == "text" {
                textBlockIndices.insert(index)
            }
            return []

        case "content_block_delta":
            guard let index = root["index"] as? Int,
                  textBlockIndices.contains(index),
                  let delta = root["delta"] as? [String: Any],
                  delta["type"] as? String == "text_delta",
                  let text = delta["text"] as? String
            else { return [] }
            return [.textDelta(text)]

        case "message_delta":
            let delta = root["delta"] as? [String: Any]
            return [.messageDelta(stopReason: delta?["stop_reason"] as? String)]

        case "message_stop":
            return [.done]

        default:
            return []
        }
    }
}
```

```swift
public struct HTTPStreamResponse: Sendable {
    public let statusCode: Int
    public let lines: AsyncThrowingStream<String, Error>

    public init(statusCode: Int, lines: AsyncThrowingStream<String, Error>) {
        self.statusCode = statusCode
        self.lines = lines
    }
}

public protocol HTTPStreamer: Sendable {
    func stream(_ request: URLRequest) async throws -> HTTPStreamResponse
}

public struct URLSessionStreamer: HTTPStreamer {
    private let session: URLSession

    public init(session: URLSession = .shared) {
        self.session = session
    }

    public func stream(_ request: URLRequest) async throws -> HTTPStreamResponse {
        let (bytes, response) = try await session.bytes(for: request)
        let status = (response as? HTTPURLResponse)?.statusCode ?? 0

        let lines = AsyncThrowingStream<String, Error> { continuation in
            let task = Task {
                do {
                    for try await line in bytes.lines {
                        continuation.yield(line)
                    }
                    continuation.finish()
                } catch {
                    continuation.finish(throwing: error)
                }
            }
            continuation.onTermination = { _ in task.cancel() }
        }
        return HTTPStreamResponse(statusCode: status, lines: lines)
    }
}
```

```swift
import Foundation

public struct ClaudeExplainer: Explainer {

    private let streamer: HTTPStreamer
    private let builder: ClaudeRequestBuilder
    private let apiKey: String

    public init(streamer: HTTPStreamer = URLSessionStreamer(),
                builder: ClaudeRequestBuilder = ClaudeRequestBuilder(),
                apiKey: String) {
        self.streamer = streamer
        self.builder = builder
        self.apiKey = apiKey
    }

    public func explain(_ utterance: Utterance) async throws -> Card? {
        let request = try builder.makeRequest(for: utterance, apiKey: apiKey)

        let response: HTTPStreamResponse
        do {
            response = try await streamer.stream(request)
        } catch let error as ExplainerError {
            throw error
        } catch {
            throw ExplainerError.network(error.localizedDescription)
        }

        switch response.statusCode {
        case 200: break
        case 429: throw ExplainerError.rateLimited
        default: throw ExplainerError.server(status: response.statusCode)
        }

        var parser = SSEParser()
        var json = ""
        var stopReason: String?

        do {
            for try await line in response.lines {
                for event in parser.consume(line: line) {
                    switch event {
                    case .textDelta(let chunk): json += chunk
                    case .messageDelta(let reason): stopReason = reason
                    case .done: break
                    }
                }
            }
        } catch {
            throw ExplainerError.network(error.localizedDescription)
        }

        if stopReason == "refusal" { throw ExplainerError.refused }

        guard let data = json.data(using: .utf8),
              let card = try? JSONDecoder().decode(Card.self, from: data)
        else { throw ExplainerError.malformedResponse }

        return card.skip ? nil : card
    }
}
```

```swift
import Foundation

public enum PipelineOutput: Sendable {
    case partial(String)
    case card(Utterance, Card)
    case failure(Utterance, ExplainerError)
}

/// Une transcripción, segmentación y explicación.
///
/// Cada frase se explica en su propia `Task`: tres frases seguidas no hacen cola.
/// Por eso las tarjetas pueden llegar desordenadas y quien las muestre debe
/// ordenar por `Utterance.startedAt`.
public struct SessionPipeline: Sendable {

    private let transcriber: any Transcriber
    private let explainer: any Explainer
    private let segmenterConfig: UtteranceSegmenter.Config

    public init(transcriber: any Transcriber,
                explainer: any Explainer,
                segmenterConfig: UtteranceSegmenter.Config = .init()) {
        self.transcriber = transcriber
        self.explainer = explainer
        self.segmenterConfig = segmenterConfig
    }

    public var outputs: AsyncStream<PipelineOutput> {
        AsyncStream { continuation in
            let task = Task {
                var segmenter = UtteranceSegmenter(config: segmenterConfig)

                await withTaskGroup(of: Void.self) { group in
                    for await (event, time) in transcriber.events {
                        if case .partial(let text) = event {
                            continuation.yield(.partial(text))
                        }
                        // Un evento nuevo puede cerrar la frase anterior por silencio...
                        if let closed = segmenter.tick(at: time) {
                            explain(closed, in: &group, into: continuation)
                        }
                        // ...y además abre o extiende la actual.
                        if let closed = segmenter.ingest(event, at: time) {
                            explain(closed, in: &group, into: continuation)
                        }
                    }
                    // Fin del audio: cierra lo que quede pendiente.
                    if let closed = segmenter.tick(at: .distantFuture) {
                        explain(closed, in: &group, into: continuation)
                    }
                    await group.waitForAll()
                }
                continuation.finish()
            }
            continuation.onTermination = { _ in task.cancel() }
        }
    }

    private func explain(_ utterance: Utterance,
                         in group: inout TaskGroup<Void>,
                         into continuation: AsyncStream<PipelineOutput>.Continuation) {
        let explainer = self.explainer
        group.addTask {
            do {
                if let card = try await explainer.explain(utterance) {
                    continuation.yield(.card(utterance, card))
                }
            } catch let error as ExplainerError {
                continuation.yield(.failure(utterance, error))
            } catch {
                continuation.yield(.failure(utterance, .network(error.localizedDescription)))
            }
        }
    }
}
```

```swift
import AVFoundation
import Observation

@MainActor
@Observable
final class AudioCapture {

    /// Nivel RMS 0…1 para el indicador de "te estoy oyendo".
    private(set) var level: Float = 0

    private let engine = AVAudioEngine()
    private var continuation: AsyncStream<AVAudioPCMBuffer>.Continuation?
    private var converter: AVAudioConverter?
    private var observer: (any NSObjectProtocol)?

    func start(outputFormat: AVAudioFormat) throws -> AsyncStream<AVAudioPCMBuffer> {
        stop()

        let input = engine.inputNode
        let inputFormat = input.outputFormat(forBus: 0)
        converter = AVAudioConverter(from: inputFormat, to: outputFormat)

        let stream = AsyncStream<AVAudioPCMBuffer> { continuation in
            self.continuation = continuation
        }

        input.installTap(onBus: 0, bufferSize: 4096, format: inputFormat) { [weak self] buffer, _ in
            guard let self else { return }
            let rms = Self.rms(of: buffer)
            Task { @MainActor in self.level = rms }
            if let converted = self.convert(buffer, to: outputFormat) {
                self.continuation?.yield(converted)
            }
        }

        // Auriculares desconectados, cambio de entrada: reconstruir el tap.
        observer = NotificationCenter.default.addObserver(
            forName: .AVAudioEngineConfigurationChange,   // NSNotification.Name, no AVAudioEngine.*
            object: engine,
            queue: .main
        ) { [weak self] _ in
            guard let self else { return }
            Task { @MainActor in _ = try? self.restart(outputFormat: outputFormat) }
        }

        engine.prepare()
        try engine.start()
        return stream
    }

    func stop() {
        if let observer {
            NotificationCenter.default.removeObserver(observer)
            self.observer = nil
        }
        if engine.isRunning {
            engine.inputNode.removeTap(onBus: 0)
            engine.stop()
        }
        continuation?.finish()
        continuation = nil
        converter = nil
        level = 0
    }

    private func restart(outputFormat: AVAudioFormat) throws {
        engine.inputNode.removeTap(onBus: 0)
        engine.stop()
        let input = engine.inputNode
        let inputFormat = input.outputFormat(forBus: 0)
        converter = AVAudioConverter(from: inputFormat, to: outputFormat)
        input.installTap(onBus: 0, bufferSize: 4096, format: inputFormat) { [weak self] buffer, _ in
            guard let self, let converted = self.convert(buffer, to: outputFormat) else { return }
            self.continuation?.yield(converted)
        }
        engine.prepare()
        try engine.start()
    }

    private func convert(_ buffer: AVAudioPCMBuffer,
                         to format: AVAudioFormat) -> AVAudioPCMBuffer? {
        guard let converter else { return nil }
        let ratio = format.sampleRate / buffer.format.sampleRate
        let capacity = AVAudioFrameCount(Double(buffer.frameLength) * ratio) + 1024
        guard let output = AVAudioPCMBuffer(pcmFormat: format, frameCapacity: capacity) else {
            return nil
        }
        var consumed = false
        var error: NSError?
        converter.convert(to: output, error: &error) { _, status in
            if consumed {
                status.pointee = .noDataNow
                return nil
            }
            consumed = true
            status.pointee = .haveData
            return buffer
        }
        return error == nil && output.frameLength > 0 ? output : nil
    }

    private static func rms(of buffer: AVAudioPCMBuffer) -> Float {
        guard let channel = buffer.floatChannelData?[0] else { return 0 }
        let count = Int(buffer.frameLength)
        guard count > 0 else { return 0 }
        var sum: Float = 0
        for i in 0..<count { sum += channel[i] * channel[i] }
        return min(1, (sum / Float(count)).squareRoot() * 8)
    }
}
```

```swift
import AVFoundation
import Foundation
import Speech
import ParlaCore

enum TranscriberSetupError: Error {
    case microphoneDenied
    case localeUnsupported
    case assetUnavailable
}

enum TranscriberPhase: Sendable, Equatable {
    case idle
    /// Fracción 0…1 de la descarga del modelo de español.
    case downloadingModel(Double)
    case ready
    case failed(String)
}

/// Transcripción en el dispositivo con la API de macOS 26.
/// El audio nunca sale de la máquina.
@MainActor
final class SpeechTranscriberEngine: Transcriber {

    /// Creado en `init` para poder ser `nonisolated let`: así satisface el
    /// requisito síncrono del protocolo `Transcriber`.
    nonisolated let events: AsyncStream<(TranscriptEvent, Date)>
    private nonisolated let relay: AsyncStream<(TranscriptEvent, Date)>.Continuation

    private let requestedLocale: Locale
    private var analyzer: SpeechAnalyzer?
    private var transcriber: SpeechTranscriber?
    private var audio: AudioCapture?
    private var pump: Task<Void, Never>?

    /// Fase de arranque, para que la UI pueda mostrar descarga o error.
    private(set) var phase: TranscriberPhase = .idle

    init(locale: Locale = Locale(identifier: "es-419")) {
        self.requestedLocale = locale
        (self.events, self.relay) = AsyncStream.makeStream()
    }

    func start() async throws {
        guard await Self.microphoneGranted() else {
            phase = .failed("micrófono denegado")
            throw TranscriberSetupError.microphoneDenied
        }
        let locale = try await resolvedLocale()
        let transcriber = SpeechTranscriber(locale: locale, preset: .progressiveTranscription)
        try await ensureAssets(for: transcriber)
        _ = try? await AssetInventory.reserve(locale: locale)

        guard let format = await SpeechAnalyzer.bestAvailableAudioFormat(
            compatibleWith: [transcriber]
        ) else { throw TranscriberSetupError.assetUnavailable }

        let capture = await AudioCapture()
        let buffers = try await capture.start(outputFormat: format)
        let inputs = buffers.map { AnalyzerInput(buffer: $0) }

        let analyzer = SpeechAnalyzer(modules: [transcriber])
        try await analyzer.start(inputSequence: inputs)

        self.transcriber = transcriber
        self.analyzer = analyzer
        self.audio = capture
        phase = .ready

        pump = Task { [weak self] in
            guard let self else { return }
            do {
                for try await result in transcriber.results {
                    let text = String(result.text.characters)
                    self.emit(result.isFinal ? .final(text) : .partial(text))
                }
            } catch {
                self.emit(.final(""))   // cierra lo pendiente
            }
        }
    }

    /// El micrófono se pide explícitamente para poder distinguir "denegado" de
    /// "no hay audio" y ofrecerle al usuario el botón a Ajustes del Sistema.
    private static func microphoneGranted() async -> Bool {
        switch AVCaptureDevice.authorizationStatus(for: .audio) {
        case .authorized: return true
        case .notDetermined: return await AVCaptureDevice.requestAccess(for: .audio)
        default: return false
        }
    }

    func stop() async {
        pump?.cancel()
        pump = nil
        await analyzer?.cancelAndFinishNow()
        analyzer = nil
        transcriber = nil
        await audio?.stop()
        audio = nil
        phase = .idle
        relay.finish()
    }

    private nonisolated func emit(_ event: TranscriptEvent) {
        relay.yield((event, Date()))
    }

    /// `es-419` puede no estar; la API resuelve al equivalente soportado.
    private func resolvedLocale() async throws -> Locale {
        if let match = await SpeechTranscriber.supportedLocale(equivalentTo: requestedLocale) {
            return match
        }
        if let fallback = await SpeechTranscriber.supportedLocale(
            equivalentTo: Locale(identifier: "es-ES")
        ) { return fallback }
        throw TranscriberSetupError.localeUnsupported
    }

    /// Descarga el modelo de español si no está instalado.
    private func ensureAssets(for module: SpeechTranscriber) async throws {
        switch await AssetInventory.status(forModules: [module]) {
        case .installed:
            return
        case .unsupported:
            throw TranscriberSetupError.assetUnavailable
        case .supported, .downloading:
            guard let request = try await AssetInventory.assetInstallationRequest(
                supporting: [module]
            ) else { return }
            phase = .downloadingModel(0)
            let progress = request.progress
            let watcher = Task { [weak self] in
                while !Task.isCancelled {
                    await MainActor.run {
                        self?.phase = .downloadingModel(progress.fractionCompleted)
                    }
                    try? await Task.sleep(for: .milliseconds(250))
                }
            }
            defer { watcher.cancel() }
            try await request.downloadAndInstall()
        @unknown default:
            throw TranscriberSetupError.assetUnavailable
        }
    }
}
```

```swift
import AppKit
import Foundation
import Observation
import SwiftData
import ParlaCore

@MainActor
@Observable
final class AppState {

    private(set) var isListening = false
    private(set) var partialText = ""
    private(set) var setupError: String?
    private(set) var needsMicrophoneAccess = false
    private(set) var cards: [CardPresentation] = []

    /// Las tres más recientes, ordenadas por cuándo se dijo la frase y no por
    /// cuándo llegó la respuesta: las llamadas se resuelven desordenadas.
    var visibleCards: [CardPresentation] {
        Array(cards.sorted { $0.utterance.startedAt < $1.utterance.startedAt }.suffix(3))
    }

    var store: CardStore?

    private var engine: SpeechTranscriberEngine?
    private var pipelineTask: Task<Void, Never>?
    private var panel: FloatingPanel?

    func toggleListening() {
        isListening ? stop() : start()
    }

    private func start() {
        guard let apiKey = KeychainStore.shared.apiKey else {
            setupError = ExplainerError.missingAPIKey.readableMessage
            return
        }
        isListening = true
        setupError = nil
        showPanel()

        let engine = SpeechTranscriberEngine()
        self.engine = engine
        let explainer = ClaudeExplainer(apiKey: apiKey)

        pipelineTask = Task {
            do {
                try await engine.start()
                needsMicrophoneAccess = false
            } catch TranscriberSetupError.microphoneDenied {
                needsMicrophoneAccess = true
                setupError = "Parla necesita acceso al micrófono."
                stop()
                return
            } catch TranscriberSetupError.localeUnsupported {
                setupError = "Tu Mac no tiene un modelo de voz en español disponible."
                stop()
                return
            } catch {
                setupError = String(describing: error)
                stop()
                return
            }
            let pipeline = SessionPipeline(transcriber: engine, explainer: explainer)
            for await output in pipeline.outputs {
                switch output {
                case .partial(let text):
                    partialText = text
                case .card(let utterance, let card):
                    partialText = ""
                    upsert(utterance, .ready(card))
                    await store?.save(utterance: utterance, card: card)
                case .failure(let utterance, let error):
                    partialText = ""
                    upsert(utterance, .failed(error))
                }
            }
        }
    }

    private func stop() {
        isListening = false
        partialText = ""
        pipelineTask?.cancel()
        pipelineTask = nil
        let engine = self.engine
        self.engine = nil
        Task { await engine?.stop() }
        panel?.orderOut(nil)
        panel = nil
    }

    private func upsert(_ utterance: Utterance, _ state: CardState) {
        if let existing = cards.first(where: { $0.id == utterance.id }) {
            existing.state = state
        } else {
            cards.append(CardPresentation(utterance: utterance, state: state))
        }
        if cards.count > 30 { cards.removeFirst(cards.count - 30) }
    }

    func retry(_ presentation: CardPresentation) {
        guard let apiKey = KeychainStore.shared.apiKey else { return }
        presentation.state = .pending
        let explainer = ClaudeExplainer(apiKey: apiKey)
        Task {
            do {
                if let card = try await explainer.explain(presentation.utterance) {
                    presentation.state = .ready(card)
                    await store?.save(utterance: presentation.utterance, card: card)
                }
            } catch let error as ExplainerError {
                presentation.state = .failed(error)
            } catch {
                presentation.state = .failed(.network(error.localizedDescription))
            }
        }
    }

    /// Abre el panel de Privacidad › Micrófono directamente.
    static func openMicrophoneSettings() {
        let url = URL(string:
            "x-apple.systempreferences:com.apple.preference.security?Privacy_Microphone")!
        NSWorkspace.shared.open(url)
    }

    private func showPanel() {
        guard panel == nil else { return }
        let panel = FloatingPanel { PanelView(state: self) }
        panel.orderFrontRegardless()
        self.panel = panel
    }
}
```

## Notas para quien ejecute el plan

- **Tareas 1-7 no necesitan Xcode.** Si `xcodebuild -version` falla, se pueden completar igual: `make test` funciona con Command Line Tools.
- **No añadir dependencias.** Si algo parece requerir un paquete nuevo, parar y preguntar.
- **`Core` no importa SwiftData ni AppKit.** Si un test del núcleo deja de correr con `make test`, lo más probable es que se haya colado un import prohibido.
- **El primer parámetro a ajustar con uso real es `silenceGap`** (0,9 s). Vive en `UtteranceSegmenter.Config` y en ningún otro sitio.
- Los nombres de las APIs de Speech están verificados contra el SDK 26.5 instalado y ejecutados en un spike. Si alguna firma no compila, leer
  `/Library/Developer/CommandLineTools/SDKs/MacOSX.sdk/System/Library/Frameworks/Speech.framework/Versions/A/Modules/Speech.swiftmodule/arm64e-apple-macos.swiftinterface`
  antes de improvisar.
